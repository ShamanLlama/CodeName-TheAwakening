# Game Design Document

The design source of truth is the **[GDD folder](gdd/README.md)**, reverse-engineered from
the shipped `alignment-1` build. Start at [gdd/README.md](gdd/README.md).

Numbers are not documented in prose. `src/data/balance.ts` is authoritative; the GDD
explains what each constant means and carries a dated snapshot in
[gdd/07-balance.md](gdd/07-balance.md).

Superseded designs are kept for provenance only and are **not** design references:

- [Archived MVP proposal](archive/GDD_mvp_proposal.md) — the pre-implementation design this
  folder replaces.
- [Archived legacy prototype](archive/GDD_legacy_prototype.md) — the percentage-influence
  and Suppression rules, replaced before `alignment-1`.

See also the [implementation plan](implementation-plan.md), [implementation
status](implementation-checklist.md), and [playtest reports](playtests/).
