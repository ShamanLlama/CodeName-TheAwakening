# Glosario de trabajo

**Versión:** 0.1 · **Fecha:** 2026-10-28 · **Estado:** referencia del prototipo.

Los términos españoles ayudan a conversar sobre el diseño; no fijan todavía una
localización de la interfaz.

| Término del juego | Uso en el GDD |
| --- | --- |
| Influence | Influencia: moneda operativa global para reclutar, expandirse y proteger la red |
| Dread | Recurso ritual procedente de sacrificios y pesadillas; no tiene ingreso pasivo |
| Followers | Seguidores locales: producen influencia, sostienen sitios y pueden perderse |
| Believers | Creyentes que todavía no pertenecen al culto; pueden ser reclutados |
| Deniers | Personas que rechazan lo sobrenatural; el reclutamiento ordinario no las convierte |
| Unaware | Población ajena a lo sobrenatural y disponible para reclutamiento |
| Losses | Población perdida permanentemente por sacrificios u oposición |
| Cell | Célula regional del culto, existente mientras mantiene seguidores |
| Exposure | Exposición: evidencia local que influye en amenazas; no causa derrota por sí sola |
| Awareness | Conocimiento global del mundo sobre el culto; frena economía y crecimiento y puede causar derrota |
| Site | Sitio ritual financiado, con preparación y requisito continuo de apoyo local |
| Supported | Con suficientes seguidores locales para sostener el sitio |
| Prepared | Con la preparación completa; para contar en el rito también necesita apoyo actual |
| Alignment | Ventana de alineación astral en la que puede iniciarse y completarse el rito |
| Doctrine | Especialización permanente de una partida, elegida una sola vez |
| Director | Sistema de reglas y azar con semilla que programa amenazas y oportunidades |
| Seed | Semilla: permite reproducir una partida junto con la secuencia de acciones |
| `alignment-1` | Identificador del conjunto de reglas actual, distinto de la versión documental |
