# Glosario de trabajo

**Versión:** 0.3 · **Fecha:** 2026-11-18 · **Estado:** referencia del juego actual.

Los términos españoles ayudan a conversar sobre el diseño; no fijan todavía una
localización de la interfaz.

| Término del juego | Uso en el GDD |
| --- | --- |
| Influence | Influencia: moneda operativa global para reclutar, expandirse y proteger la red |
| Dread | Recurso ritual procedente de sacrificios y pesadillas; no tiene ingreso pasivo |
| Followers | Seguidores locales: producen influencia, sostienen sitios y pueden perderse |
| Believers | Creyentes que todavía no pertenecen al culto; pueden ser reclutados |
| Deniers | Personas que rechazan lo sobrenatural; el reclutamiento ordinario no las convierte |
| Unaware | Población ajena a lo sobrenatural y disponible para reclutamiento |
| Losses | Población perdida permanentemente por sacrificios u oposición |
| Cell | Célula regional del culto, existente mientras mantiene seguidores |
| Exposure | Exposición: evidencia local que influye en amenazas; no causa derrota por sí sola |
| Awareness | Conocimiento global del mundo sobre el culto; frena economía y crecimiento y puede causar derrota |
| Site | Sitio ritual financiado, con preparación y requisito continuo de apoyo local |
| Supported | Con suficientes seguidores locales para sostener el sitio |
| Prepared | Con la preparación completa; para contar en el rito también necesita apoyo actual |
| Alignment | Ventana de alineación astral en la que puede iniciarse y completarse el rito |
| Talent tree | Árbol de talentos de una partida (desde `alignment-5`, reemplaza la doctrina): tres ramas (Congregation, Hidden hand, Harbinger) de cuatro nodos — raíz, dos medios excluyentes y remate. No se completa en una partida |
| Seal | Sello: permiso para tomar un talento; se abren por tiempo (5 en Normal, 6 en Easy, 4 en Hard) y cada talento cuesta más Influence que el anterior |
| Capstone | Remate: último nodo de una rama; desde `alignment-6` cambia cómo se gana (The Great Procession, The world forgets, Dreams of R'lyeh) |
| Bury | Enterrar el registro (`bury`): Influence a cambio de bajar la awareness mundial, con precio creciente por uso |
| Restore | Restaurar el sitio (`restore`): Influence a cambio de recuperar meses que quitó una amenaza oculta ignorada |
| Cornered | Amenaza acorralada: no se puede obstruir ni silenciar; solo dispersar o aguantar |
| Doctrine | Especialización de una partida hasta `alignment-4`; reemplazada por el árbol de talentos |
| Director | Sistema de reglas y azar con semilla que programa amenazas y oportunidades |
| Seed | Semilla: permite reproducir una partida junto con la secuencia de acciones |
| Obstruct | Obstruir (`counter`): detener una amenaza con Influence; quema las conexiones de la región 12 meses |
| Scatter | Dispersar (`scatter`): la célula se oculta 8 meses; la amenaza no encuentra a nadie y la célula no recluta, no ingresa ni sostiene su sitio |
| Silence | Silenciar (`silence`): detener una amenaza con Dread; las desapariciones suman awareness |
| `alignment-6` | Identificador del conjunto de reglas actual (juego 0.8.0), distinto de la versión documental. `alignment-1` a `alignment-5` son los anteriores; el [registro de versiones](../../playtests/versiones.md) dice qué juego usó cada uno |
